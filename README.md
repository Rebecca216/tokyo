## 🌟 核心特色 (Features)

1. **跨平台盤口數據整合**：
   - 整合 Trip.com、易遊網 ezTravel、Klook、Agoda，以及長榮航空、中華航空、星宇航空、台灣虎航、樂桃航空、日本航空 JAL、全日空 ANA 官網報價。
   - 區分「來回機票」與「機加酒 (Flight + Hotel Package)」雙方案。
2. **智慧降價提醒引擎 (Smart Alert Engine)**：
   - **機票 Alert**：來回機票價格 **< NT$ 17,000** 時標示特惠並觸發通知。
   - **機加酒 Alert**：價格介於 **NT$ 17,000 – 27,000** 且飯店評分 **中等以上 (≥7.5)** 且 **位於交通方便區域 (JR/地鐵 1-5 分鐘內)** 時發出降價通知。
   - 支援桌面瀏覽器推播 Notifications API、站內 Toast 提醒與自訂警示門檻設定。
3. **2x2 最低價格比較矩陣**：
   - 快速比較 高雄/桃園 ↔ 成田/羽田 之最低報價。
4. **極簡舒服無漸層實色風格 (Flat Light Theme)**：
   - 採用舒服大方的平面化現代質感，閱讀不刺眼。
5. **完全無需安裝伺服器**：
   - 相容 GitHub Pages 免費靜態託管與本地直接開啟。
